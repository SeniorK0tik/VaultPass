1«Сейф» — шесть экранов, варианты для быстрого окна и списка

Допущения: локальное шифрование без облака, одно хранилище, четыре типа записей (пароли, заметки, ключи API, документы). Быстрый доступ — резидентное мини-окно у трея, вызывается горячей клавишей поверх любого приложения; главное действие — Enter копирует пароль и окно закрывается. Оформление — Nocturne: тёмный фон, контурные кнопки, акцент линией, без заливок.
