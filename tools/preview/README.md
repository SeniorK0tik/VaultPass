# Стенд визуальной проверки

Открывает экраны `ui/` в обычном браузере с подставным `window.__TAURI__`,
чтобы сверять вёрстку с макетом без полной сборки Tauri. Данные — те же,
что нарисованы в макете.

```bash
./tools/preview/run.sh            # снимет все девять экранов в docs/screens/
./tools/preview/run.sh --serve    # поднимет сервер и не будет снимать
```

Требуется `google-chrome` (или `chromium`) и Python 3.
